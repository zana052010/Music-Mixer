Установщик Music Mixer для Windows 10/11 (x64). Ничего дополнительно ставить не нужно.

Внутри:
- приложение и среда .NET 8;
- FFmpeg (сборка BtbN GPL, с фильтром rubberband);
- поиск и загрузка с YouTube встроены в приложение (YoutubeExplode), отдельные программы не нужны;
- Demucs (PyTorch для процессора) с заранее скачанной моделью htdemucs, интернет для разделения не нужен;
- BASS для воспроизведения.

Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае».

BASS бесплатен только для некоммерческого использования (лицензия un4seen.com).

## Исправления

- YouTube снова работает при региональных настройках Windows «Россия»/«Беларусь»: региональная проверка библиотеки YoutubeExplode обходится внутри программы, системные настройки не меняются.
